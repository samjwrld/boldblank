# Design System Documentation

## Typography

### Font Families

| Type | Font Name | Usage |
| :--- | :--- | :--- |
| **Display** | **Syncopate** | Used for large headings, hero titles, and impactful statements. |
| **Sans** | **Space Grotesk** | Used for body text, subtitles, and general UI elements. |
| **Mono** | **Monospace** | Used for technical details, metadata, and code snippets. |

### Heading Styles

-   **Hero Titles / Large Headings**: `font-display`, `font-bold`, often uppercase.
-   **Section Headings**: `font-display`, `font-bold`.
-   **Subtitles**: `font-sans`, often `text-neutral-400` or `text-light`.
-   **Micro-labels / Tags**: `font-mono`, uppercase, tracking-widest.

## Color Palette

| Color Name | Hex Code | Description | Usage |
| :--- | :--- | :--- | :--- |
| **Accent** | `#CCFF00` | **Acid Lime** | Primary action buttons, highlights, active states, and emphasis. |
| **Dark** | `#050505` | **Void Black** | Main background color. |
| **Light** | `#E0E0E0` | **Off-White** | Primary text color. |
| **Surface** | `#0F0F0F` | **Dark Grey** | Secondary background for cards, sections, and panels. |
| **Glass** | `rgba(255, 255, 255, 0.05)` | **Transparent White** | Subtle overlays and glassmorphic effects. |

### Additional Colors

-   **Neutral**: Tailwind's default neutral palette is used for varying shades of grey (e.g., `text-neutral-400`, `text-neutral-500`).
-   **White**: `#FFFFFF` used for high-contrast text and borders.
